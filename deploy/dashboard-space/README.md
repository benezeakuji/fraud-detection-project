# Fraud Detection Analyst Dashboard

Streamlit analyst dashboard for the MIT Professional Master's Project
*"Design and Implementation of a Machine Learning-Based Fraud Detection
System for Electronic Transactions in Nigeria"* (Benjamin Ezeakuji, Miva
Open University).

Scores the real 42,559-transaction held-out test set (71 fraud) with the
trained XGBoost (cost-sensitive) model, and shows a summary, a flagged-
transaction risk queue, and a per-transaction SHAP explanation.

Source: https://github.com/benezeakuji/fraud-detection-project
